# services/rules-engine

Deterministic permit evaluation engine (Python / FastAPI). The source of truth
for permit outputs. Built across EPIC-03 (T03-01–T03-06). Scaffold only.

Implements the specs: rule object (T00-01), evaluation order, conflict resolution
(T03-03), sequencing (T00-04), explainability (T00-05), known-unknown detection
(T03-06).
